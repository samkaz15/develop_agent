# 法人設立〜開業 チェックリスト

> 設立から開業までの**抜け漏れ防止**用。詳細な期限は [`legal-procedure-tracker.csv`](../templates/legal-procedure-tracker.csv)、工程は [`wbs-incorporation.csv`](../templates/wbs-incorporation.csv) で管理する。期限・要件は一般的な目安であり、士業・所管機関の一次情報で確認する。

## A. 事業・資金（Gate L1 / L2）

- [ ] 「〇〇をやります」を1文で言える（Launch Brief §1・§2）
- [ ] Owner が Go / No-Go を判断した（Gate L1）
- [ ] 必要資金の根拠（設立費用・初期投資・運転資金・予備費）を記録した
- [ ] 3シナリオ（Worst/Base/Best）で資金ショート月を確認した
- [ ] 生活防衛資金を事業資金と別に確保した
- [ ] 資本金・調達構成を Owner が決定した（Gate L2、税理士確認）

## B. 設立準備（Gate L3）

- [ ] 法人形態を比較して決めた
- [ ] 商号・本店所在地・事業目的・役員・事業年度を確定した
- [ ] 類似商号・商標を事前調査した
- [ ] 許認可の要否を所管の一次情報と行政書士で確認した
- [ ] 定款案を司法書士等がレビューした
- [ ] 会社実印・印鑑証明書を準備した
- [ ] 士業（司法書士・税理士・社労士）を選定・依頼した
- [ ] Owner が設立内容を確定した（Gate L3）

## C. 設立手続

- [ ] 定款認証（株式会社の場合）
- [ ] 出資金の払込み・払込証明書
- [ ] 登記申請書類の作成
- [ ] 設立登記の申請（＝設立日を `legal-procedure-tracker.csv` に入力）
- [ ] 登記事項証明書・印鑑証明書を取得（複数通）

## D. 設立後の届出（設立日から期限が始まる）

- [ ] 税務署: 法人設立届出書 / 青色申告承認申請書 / 給与支払事務所等の開設届出書（該当時）
- [ ] 都道府県・市区町村: 法人設立届出書（自治体ごとに期限・様式が異なる）
- [ ] 年金事務所: 健康保険・厚生年金保険の新規適用届・資格取得届
- [ ] 労基署・ハローワーク: 労働保険・雇用保険の手続（従業員を雇用する場合）
- [ ] インボイス登録・消費税の課税/免税を税理士と判断した
- [ ] 届出期限トラッカーに全期限を登録し、担当を割り当てた

## E. バックオフィス

- [ ] 法人口座を開設した
- [ ] 会計・請求・経費精算の運用を決めて導入した
- [ ] 労務・勤怠・給与計算の運用を決めて導入した（雇用時）
- [ ] 契約・電子署名・書類保管のルールを決めた
- [ ] 規程類（経費規程・承認フロー・必要時は就業規則）を整えた
- [ ] 認証情報をパスワード管理ツールに集約し、2段階認証を有効にした

## F. 補助金・融資

- [ ] 国・都道府県・市区町村・支援機関の制度を公式情報で調べた
- [ ] 適合度と申請期限をカレンダー化した
- [ ] **交付決定前の発注・契約・支払をしていない**（不可の制度）
- [ ] 後払いの入金までのつなぎ資金を確保した
- [ ] 融資申込用の創業計画書を作成した

## G. マーケティング・表示

- [ ] ターゲット・チャネル・ファネルKPIを決めた
- [ ] コンテンツカレンダーを作成した
- [ ] 計測（UTM・KPI-KGI）を設定した
- [ ] 特商法表記・プライバシーポリシー・利用規約・広告表示（ステマ規制含む）を確認した

## H. 開業前最終確認（Gate L4）

- [ ] 届出・口座・ツール・規程・表示・予実管理の準備が完了している
- [ ] 予実管理表（余日管理表）の予算が確定し、実績入力の担当と頻度が決まっている
- [ ] 月次レビューの日程が決まっている
- [ ] Owner が開業を承認した（Gate L4）
