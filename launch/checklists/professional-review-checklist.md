# 士業・専門家レビュー チェックリスト

> AI（Business Launch Agent）は情報整理・比較・書類案・試算までを担い、**次の項目は必ず該当する専門家の確認を経てから確定**する。AIが「問題ない」と断定した項目も、確定前に専門家確認が必要。
> 費用・依頼範囲は専門家ごとに異なる。まず無料相談等で「何を依頼すべきか」を整理し、依頼内容を Launch Brief §12 に記録する。

| 領域 | 確認が必要な事項 | 専門家 | 確認の時期（Gate / WBS） | 依頼内容の例 |
|---|---|---|---|---|
| 設立・登記 | 定款の記載、事業目的、機関設計、登記申請書類 | 司法書士 | Gate L3 / 2.5・3.3 | 定款案のレビュー、登記申請の代理 |
| 許認可 | 事業に必要な許認可・登録の要否と要件 | 行政書士 | 2.4 | 許認可の調査・申請 |
| 税務 | 青色申告・消費税（課税/免税・インボイス）・源泉所得税の特例・決算月・役員報酬の設計 | 税理士 | Gate L2 / 1.3・4.2・4.6 | 税務届出、顧問契約、役員報酬の確認 |
| 社会保険・労働保険 | 適用の要否、資格取得、規程、36協定、雇用書面 | 社会保険労務士 | 4.4・4.5・5.5・5.6 | 手続の代理、就業規則・書面の作成確認 |
| 契約・規約・表示 | 利用規約、契約雛形、プライバシーポリシー、特商法表記、広告表示（景表法・ステマ規制） | 弁護士 | 5.4・7.5 | 規約レビュー、雛形の確認 |
| 融資・資金調達 | 創業計画書、自己資金の見せ方、保証・制度融資 | 金融機関・商工会議所・税理士 | 6.3 | 創業計画書の相談 |
| 補助金の申請 | 要件・対象経費・交付決定前着手の可否・実績報告 | 申請支援を行う専門家・支援機関 | 6.4 | 申請書のレビュー |

## AIが専門家の代わりにしてはいけないこと

- 個別事案についての法的・税務的な結論の断定（「この場合は届出不要です」等）
- 登記・税務・社会保険・労働保険の申請そのものの代理
- 契約・規約の最終確定、納税額・保険料の最終確定
- 許認可の要否の断定
- 専門家の確認が済んでいない内容を「確認済み」と記載すること

## 確認依頼のテンプレート

```
【確認依頼】{{PROJECT_NAME}} / {{領域}}
- 事業の概要（1〜2文）:
- 確認してほしい事項（質問は具体的に）:
- 前提（Launch Brief の該当セクション）:
- 期限（Gate / WBS番号）:
- 添付資料:
- AIが作成した案である旨（根拠・出典URL・確認日を添付）:
```
