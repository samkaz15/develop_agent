## 2. 調達構成

| 調達源 | 金額 | 条件・返済 | 実行見込み時期 | 確度 |
|---|---|---|---|---|
| 資本金（自己資金） | | 返済不要・信用力に影響 | 設立時 | |
| 役員借入金 | | 契約書で条件を明記 | | |
| 日本政策金融公庫等の融資 | | 自己資金要件・金利は最新を確認 | | |

| 補助金・助成金 | | 後払い・交付決定前着手不可が多い | | |
| 出資（外部投資家） | | 希薄化・条件 | | |

**生活防衛資金**: 創業者の生活費◯か月分は、資本金・事業資金とは別に確保する（事業が止まっても生活が止まらないため）。

## 3. 資本金の決め方（判断軸）

| 判断軸 | 確認内容 | 結果 |
|---|---|---|
| ① 資金繰り | Worstシナリオで最低ランウェイを満たす最小資本金はいくらか | |
| ② 信用力 | 取引先・金融機関・口座開設で必要な見え方 | |
| ③ 融資との関係 | 自己資金の額が融資可否・限度額に与える影響（制度は改定されるため最新を確認） | |
| ④ 許認可要件 | 業種により資本金・純資産の要件がある（要否は所管の一次情報で確認） | |
| ⑤ 税務 | 資本金額で変わる税の取扱い（均等割の区分・消費税の免税の扱い・各種特例の対象範囲など） | 税理士確認 |
| ⑥ 将来の調達 | 増資・投資受入時の影響 | |
| ⑦ 手元に残す額 | 事業とは別に創業者が確保する額 | |

> 資本金は「1円からでも設立可能」だが、可能であることと適正であることは別。必ず①〜⑦で根拠を残す。
