## 4. セキュリティ・権限設計

| 項目 | 方針 |
|---|---|
| 認証情報（APIキー・パスワード・アプリパスワード） | パスワード管理ツールまたは各サービスのシークレット機能に保管。**スプレッドシート・リポジトリ・チャットに平文で置かない**。漏えいの疑いがあれば直ちに無効化・再発行 |
| 2段階認証 | 会計・口座・メール・クラウドストレージで必須 |
| 権限 | 最小権限。士業・外注には閲覧/編集の範囲を限定して付与 |
| 退職・契約終了時 | アカウントの無効化手順を決めておく |
| 個人情報 | 顧客・従業員の個人情報は必要最小限だけ保持し、AIへの入力前にマスキングする |
