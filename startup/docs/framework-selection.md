# フレームワーク選択ガイド

Version 1.0.0 / 2026-09-29

全部を埋めることを目的にしない。今の意思決定に必要な1〜3個を選び、選択理由をstrategy.frameworksへ記録する。

| 状況 | 最初に使うもの | 必要になった場合の拡張 | 成果物と次の作業 |
|---|---|---|---|
| 顧客・課題が曖昧 | ICP / JTBD / Pain-Gain | Persona、VOC、Customer Journey、購買障壁 | customer → 顧客検証Task |
| 市場・競合を知りたい | 3C / 競合比較 | PESTEL、5 Forces、TAM/SAM/SOM、市場成長率、Landscape、Positioning Map | 根拠付きreference → strategy |
| 価値が伝わらない | Value Proposition Canvas / USP・UVP | STP、Moat、Switching Cost、Network Effect、Brand Equity | company.value_proposition → creative |
| 収益モデルを決める | Lean Canvas / Revenue・Pricing Model | Business Model Canvas、Unit Economics、CAC、LTV、LTV/CAC、Payback、Contribution Margin | 価格/原価仮説 → 検証とfinance |
| 優先する市場を決める | SWOT / TOWS | Ansoff、BCG、Blue Ocean、Porterの競争戦略 | 選択肢と判断 → decision |
| 獲得・継続が伸びない | Funnel / AARRR | Growth Loop、Cohort、Retention Curve、Referral Loop（Pirate MetricsはAARRRと同義） | KPIのボトルネック → experiment |
| 仮説を実行に移す | MVP / Build-Measure-Learn | Lean Startup、Hypothesis Testing、Experiment Backlog、ICE/RICE、Impact-Effort | 要件→Task→結果→knowledge |

市場規模やLTVは計算方法・期間・前提・出典を必ず残す。未取得を0として扱わない。
各分析の最後に「何を判断できたか／何が未確認か／次Task ID／どの価値ドライバーにつながるか」を書く。
