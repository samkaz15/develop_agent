HP、LP、SNS、広告の制作物を同じ事業KPIに接続する。
デザイン基準は [Design Package](../README.md)、実績の正本は [Startup台帳](../../startup/README.md)、HP部品は [HP Template](../../hp_template/README.md)。

## 実行手順

1. Project/KPI/対象顧客/Offerを確認し、[ブリーフ](creative-brief.md) を記入する。
2. referenceを分析し、Hook/本文/ビジュアル/CTAの案を制作する。
3. creativeに版・素材パス・関連Template IDを登録する。原稿→素材制作→編集→レビュー→公開準備→計測までtaskを分解する。
4. ボトルネックを数値と定性情報で確認する。好みだけで改善効果を断定しない。
5. [実験計画](experiment-plan.md) を作り、主な変更変数・対照・対象・期間・停止条件を先に定める。
6. 公開/予算変更は承認後に実施する。未承認の案はdraftのまま残す。
7. 結果をexperimentに記録し、scale/continue/modify/stopを選択する。データ不足は不足と記録する。
8. knowledgeに学び・適用条件・失敗理由・次Task IDを残す。再利用に十分な根拠がある場合のみ共通テンプレートの版を更新する。

比較条件の異なるSNS投稿の単純比較をA/Bテストと呼ばない。流入・配信・季節性・対象顧客の影響を分けて解釈する。
CVRだけでなく有効問い合わせ、売上、継続、粗利への接続も確認する。
