# Service Site Starter v1.0.0

`index.html` をブラウザで開くとプレビューできる。ビルド・外部フォント・JavaScript・外部画像への依存なし。
案件側へこのディレクトリをコピーし、`styles.css` のトークンと本文を編集する。

## 構成

ファーストビュー → 顧客課題 → サービス → 支援工程 → よくある質問 → 相談導線。
色/余白/文字サイズはCSS変数で管理する。モバイル対応、スキップリンク、フォーカス、reduced-motionを用意。
`data-event` は計測実装時に使う目印であり、現時点ではデータ送信しない。

## 公開前に必ず変更

- 仮のブランド名・コピー・提供内容を確定した事業情報へ変更。
- 価格、運営者、連絡先、利用条件を必要に応じて追加。
- 相談先を実URLまたは動作確認済みフォームへ接続。現状は接続先未設定と表示する。
- title/description/OGP/canonical、robotsのindex方針を確定。
- 実績は根拠と掲載許諾があるものだけ追加。
- `../../checklists/release.md` を確認する。このスターターだけでは公開準備完了ではない。

WordPressではコードを参考に案件の子テーマやカスタムHTMLブロックへ移植し、スタイル干渉を確認する。インストール可能なWordPressテーマではない。
